Joint work with **F. Hoffmann-La Roche AG**.

Designed an orthogonal neural network architecture using quantum gates and an efficient learning algorithm to train perfectly orthogonal neural networks, then extended it to an actual quantum architecture and benchmarked its performance on Medical MNIST image classification {% cite landman2022quantum %}.
